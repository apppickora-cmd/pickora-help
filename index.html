⚡ 5 ചുവടിൽ തുടങ്ങാം

  1. ആപ്പ് തുറന്ന് Create account അമർത്തുക. ഇമെയിലും പാസ്‌വേഡും (രണ്ടുതവണ) കൊടുക്കുക.
  2. മുകളിൽ ഇടത് ☰ → Settings: വണ്ടിയുടെ പേരും UPI ID-യും ചേർത്ത് Save changes അമർത്തുക.
  3. താഴെ Parties → +: കുട്ടികളെ ഓരോരുത്തരെയായി ചേർക്കുക.
  4. ഫീസ് കിട്ടിയാൽ Fees → ആ കുട്ടി → Mark paid.
  5. ബാക്കി ഉള്ളവർക്ക് Remind അമർത്തി QR കോഡ് സഹിതം WhatsApp-ൽ അയയ്ക്കുക.
മാസത്തിൽ ഒരിക്കൽ ബാക്കപ്പ് എടുക്കാൻ മറക്കരുത് (☰ → Backup & Restore).

Android ഫോൺ (Chrome)

  3. Install app അല്ലെങ്കിൽ Add to Home screen അമർത്തി Install ചെയ്യുക.

iPhone (Safari)

  1. ലിങ്ക് Safari-യിൽ തുറക്കുക.
  2. താഴെ Share ബട്ടൺ അമർത്തുക.
  3. Add to Home Screen → Add.
ഹോം സ്ക്രീനിൽ Pickora ഐക്കൺ വരും. ഇനി ലിങ്ക് തിരയേണ്ട, ഐക്കണിൽ അമർത്തിയാൽ മതി.
ആദ്യത്തെ തവണ ഇന്റർനെറ്റ് ഓണായിരിക്കണം.
🔐 അക്കൗണ്ട്, ലോഗിൻ, പാസ്‌വേഡ് മറന്നാൽ

പുതിയ അക്കൗണ്ട്

  1. Create account അമർത്തുക.
  2. ഇമെയിൽ കൊടുക്കുക.
  3. Password (കുറഞ്ഞത് 6 അക്ഷരം) കൊടുത്ത് Confirm password കോളത്തിൽ അതേ പാസ്‌വേഡ് വീണ്ടും കൊടുക്കുക. രണ്ടും ഒരുപോലെ അല്ലെങ്കിൽ ചുവന്ന അക്ഷരത്തിൽ പറയും.
പുതിയ അക്കൗണ്ടിന് 30 ദിവസം സൗജന്യം. അതിന് ശേഷം “Access expired” എന്ന് കാണും. അപ്പോഴും നിങ്ങളുടെ ഡാറ്റ നഷ്ടപ്പെടില്ല. സഹായ നമ്പറിൽ ബന്ധപ്പെട്ടാൽ വീണ്ടും തുറക്കും.

പാസ്‌വേഡ് മറന്നാൽ

  1. ലോഗിൻ സ്ക്രീനിൽ Forgot password? അമർത്തുക.
  2. ഇമെയിൽ കൊടുത്ത് Send reset link.
  3. ഇമെയിൽ തുറന്ന് ലിങ്ക് ഫോണിൽ അമർത്തുക. ഇമെയിൽ കാണുന്നില്ലെങ്കിൽ Spam ഫോൾഡർ നോക്കുക.
  4. വരുന്ന സ്ക്രീനിൽ പുതിയ പാസ്‌വേഡ് രണ്ടുതവണ കൊടുത്ത് Save new password.

പാസ്‌വേഡ് മാറ്റാൻ / ലോഗൗട്ട്

☰ → Account. ലോഗൗട്ട് ചെയ്യുമ്പോൾ ഒരു ചോദ്യം വരും: Yes, log out അമർത്തിയാൽ മാത്രം പുറത്തുപോകും.

⚙️ ആദ്യം ചെയ്യേണ്ട സെറ്റിങ്ങുകൾ

☰ → Settings തുറക്കുക:

  • Vehicle / operator name: നിങ്ങളുടെ വണ്ടിയുടെ/സ്ഥാപനത്തിന്റെ പേര്. രസീതിലും സന്ദേശങ്ങളിലും ഇത് വരും.
  • UPI ID: നിങ്ങൾക്ക് പണം കിട്ടുന്ന UPI വിലാസം (ഉദാ: 98xxxxxxxx@okaxis). GPay/PhonePe-യിൽ ഇത് കാണാം. ഇതിൽ നിന്നാണ് പേയ്‌മെന്റ് QR ഉണ്ടാകുന്നത്.
  • WhatsApp group link: രക്ഷിതാക്കളുടെ ഗ്രൂപ്പിന്റെ invite link (https://chat.whatsapp.com/…). ഗ്രൂപ്പ് നോട്ടീസിന് വേണ്ടി.
മാറ്റങ്ങൾ വരുത്തിയ ശേഷം Save changes അമർത്തണം. അമർത്താതെ പുറത്തുപോയാൽ “Discard changes?” എന്ന് ചോദിക്കും.
UPI ID രണ്ടുതവണ പരിശോധിക്കുക. ഒരു അക്ഷരം തെറ്റിയാൽ രക്ഷിതാക്കളുടെ പണം മറ്റൊരാൾക്ക് പോകാം.

☰ → Vehicles: വണ്ടിയുടെ പേരും രജിസ്ട്രേഷൻ നമ്പറും (ഓപ്ഷണൽ) മാറ്റാം. ഒന്നിലധികം വണ്ടി ഉണ്ടെങ്കിൽ ഭാഗം 10 നോക്കുക.

  3. വിവരങ്ങൾ കൊടുത്ത് Save.

തിരുത്താനും ഒഴിവാക്കാനും

ലിസ്റ്റിൽ ആ കുട്ടിയെ ടാപ്പ് ചെയ്യുക. തുറക്കുന്ന സ്ക്രീനിൽ: Payment history, Edit (തിരുത്താൻ), WhatsApp parent, Remove (ഒഴിവാക്കാൻ).

Remove അമർത്തിയാൽ ആ കുട്ടിയുടെ പേയ്‌മെന്റ് രേഖകളും പോകും, തിരിച്ചെടുക്കാൻ പറ്റില്ല. അതുകൊണ്ട് ഉറപ്പ് ചോദിക്കും. സംശയമുണ്ടെങ്കിൽ മുമ്പ് ബാക്കപ്പ് എടുക്കുക.
ലിസ്റ്റിന് മുകളിലെ സെർച്ച് ബോക്സിൽ പേര്, ഫോൺ, സ്റ്റോപ്പ് എന്നിവ എഴുതി ആരെയും വേഗം കണ്ടെത്താം. കുട്ടികൾ A-Z ക്രമത്തിലാണ്.
ഫീസ് കണക്കാക്കുന്നത് കുട്ടിയെ ആപ്പിൽ ചേർത്ത മാസം മുതലാണ്.
💳 ഫീസ് കിട്ടിയാൽ രേഖപ്പെടുത്താൻ (Mark paid)

Fees ടാബിൽ മുകളിൽ മൂന്ന് ബട്ടൺ: Pending (ബാക്കി ഉള്ളവർ), Paid (എല്ലാം അടച്ചവർ), All (എല്ലാവരും). ഓരോ കുട്ടിയുടെയും താഴെ ആകെ ബാക്കിയും ഏതൊക്കെ മാസത്തെ ബാക്കി എന്നും കാണും.

പണം രേഖപ്പെടുത്തുന്ന വിധം

  1. ആ കുട്ടിയുടെ Mark paid അമർത്തുക.
  2. Amount received കോളത്തിൽ കിട്ടിയ തുക എഴുതുക. എത്ര വേണമെങ്കിലും ആകാം: പകുതിയോ, ഒരു മാസത്തേതോ, പല മാസത്തേതോ.
  3. ആപ്പ് ആ തുക ഏറ്റവും പഴയ ബാക്കി മാസം മുതൽ തനിയെ വീതിച്ച് ചേർക്കും. താഴെ “This payment will be added as” എന്നിടത്ത് ഏത് മാസത്തിന് എത്ര എന്ന് സേവ് ചെയ്യുന്നതിന് മുമ്പ് കാണാം.
  4. Mode: Cash / UPI / Bank തിരഞ്ഞെടുക്കുക.
  5. Save payment അമർത്തുക.

വേഗത്തിൽ ചെയ്യാൻ

  • All pending: ബാക്കി മുഴുവൻ ഒറ്റയടിക്ക്.
  • + next month, + 3 months: ബാക്കിയും വരുന്ന മാസങ്ങളും കൂടി.
  • Start from month: ഏതെങ്കിലും ഒരു മാസം മുതൽ തുടങ്ങാൻ (ഉദാ: നവംബർ മാത്രം).
പല മാസത്തേക്ക് ഒരുമിച്ച് വാങ്ങിയാൽ ഒറ്റ രസീത് സന്ദേശം വരും. Send receipt അമർത്തി WhatsApp-ൽ അയയ്ക്കാം.

തെറ്റ് പറ്റിയാൽ

കുട്ടിയുടെ താഴെ View payment history → ഓരോ മാസവും: Paid / Partial / Due. ഓരോ പേയ്‌മെന്റിനും Receipt (രസീത്), Edit (തിരുത്തൽ), Delete (ഒഴിവാക്കൽ, ഉറപ്പ് ചോദിക്കും).

മുൻകൂർ അടച്ച തുക “ബാക്കി” ആയി കണക്കാക്കില്ല. കുട്ടിയുടെ കാർഡിൽ “Advance taken” എന്ന് കാണിക്കും.
🔔 ബാക്കി ഓർമ്മിപ്പിക്കാൻ (Remind, QR, ഗ്രൂപ്പ് നോട്ടീസ്)

ഒരു രക്ഷിതാവിനെ ഓർമ്മിപ്പിക്കാൻ

  1. Fees ടാബിൽ ബാക്കി ഉള്ള കുട്ടിയുടെ Remind അമർത്തുക.
  2. പേയ്‌മെന്റ് QR കോഡും സന്ദേശവും കാണും. സന്ദേശത്തിൽ ബാക്കി ഉള്ള എല്ലാ മാസവും ആകെ തുകയും ഉണ്ടാകും. QR-ലും ആകെ തുക മുൻകൂട്ടി നിറഞ്ഞിരിക്കും.
  3. Send QR + message അമർത്തുക. ഫോണിന്റെ share ലിസ്റ്റ് തുറക്കും.
  4. WhatsApp തിരഞ്ഞെടുത്ത്, രക്ഷിതാവിന്റെ ചാറ്റ് തിരഞ്ഞെടുക്കുക. ചിത്രവും സന്ദേശവും ഒരുമിച്ച് പോകും. Send അമർത്തുക.
ചാറ്റ് നിങ്ങൾ തന്നെ തിരഞ്ഞെടുക്കണം (രക്ഷിതാവിന്റെ നമ്പർ സ്ക്രീനിൽ കാണിക്കും, തിരയാൻ എളുപ്പം). QR ഇല്ലാതെ സന്ദേശം മാത്രം മതിയെങ്കിൽ Text only.
QR വരണമെങ്കിൽ Settings-ൽ UPI ID ചേർത്തിരിക്കണം.

ഗ്രൂപ്പിൽ പൊതുവായ അറിയിപ്പ് (അവധി, സമയം മാറ്റം)

  1. ☰ → Group notice.
  2. സന്ദേശം എഴുതുക, അല്ലെങ്കിൽ Holiday / Time change / Fee due / Running late ബട്ടൺ അമർത്തി തയ്യാറായ സന്ദേശം എടുക്കുക.
  3. Copy & open group അമർത്തുക. സന്ദേശം കോപ്പി ആകും, WhatsApp ഗ്രൂപ്പ് തുറക്കും.
  4. ഗ്രൂപ്പിൽ പേസ്റ്റ് ചെയ്ത് അയയ്ക്കുക.
WhatsApp ഗ്രൂപ്പിൽ ആപ്പിന് നേരിട്ട് സന്ദേശം അയയ്ക്കാൻ അനുവാദമില്ല. അതുകൊണ്ടാണ് “കോപ്പി ചെയ്ത് ഗ്രൂപ്പ് തുറക്കുക” എന്ന രീതി. ഗ്രൂപ്പ് ലിങ്ക് Settings-ൽ ചേർത്തിരിക്കണം.
🚌 ട്രിപ്പ് / വാടക വരവും പാർട്ടികളും

സ്കൂൾ ഫീസല്ലാതെ കിട്ടുന്ന വരവ് (ടൂർ, വിവാഹ ഓട്ടം, ദിവസ വാടക) ഇവിടെ രേഖപ്പെടുത്തുക.

ചേർക്കാൻ

  1. Money ടാബ് → Trip income → +.
  2. Party name (ആർക്ക് വേണ്ടി), Mobile number, ഇനം (Trip / Daily hire / Wedding / Other), Amount, Date, Payment: Paid അല്ലെങ്കിൽ Pending, Received by (Cash/UPI/Bank), Note.

പേര്, മൊബൈൽ, കുറിപ്പ് എന്നിവ നിർബന്ധമല്ല. തുകയും തീയതിയും മാത്രം മതി.

പണം പിന്നീടാണ് കിട്ടുന്നതെങ്കിൽ (Pending)

  • Mark paid അമർത്തുക. കിട്ടിയ തുകയും Cash/UPI-യും തീയതിയും കൊടുക്കുക.
  • ഭാഗികമായി കിട്ടിയാലും മതി. ഉദാഹരണം: ₹500-ൽ ₹300 കിട്ടിയാൽ 300 എഴുതുക. ബാക്കി ₹200 pending ആയി തുടരും, പിന്നീട് അതും Mark paid ചെയ്യാം.
  • Remind: ബാക്കി തുകയ്ക്ക് QR സഹിതം WhatsApp-ൽ.
Pending ആയ തുക വരവിൽ ചേരില്ല. പണം കിട്ടി Paid ആക്കുമ്പോൾ ആ മാസത്തെ വരവിൽ ചേരും.

പാർട്ടികളുടെ കണക്ക്

Parties ടാബ് → മുകളിൽ Parties ഭാഗം: ഓരോ പാർട്ടിയുടെയും ബാക്കി തുക. ഒരാളെ അമർത്തിയാൽ അവരുടെ മുഴുവൻ ഹിസ്റ്ററി, ഒറ്റ Remind-ൽ എല്ലാ ബാക്കിയും അയയ്ക്കാം.

ഒരു കുട്ടിയുടെ രക്ഷിതാവിന്റെ ഫോൺ നമ്പറും ട്രിപ്പ് പാർട്ടിയുടെ നമ്പറും ഒന്നാണെങ്കിൽ ആപ്പ് ഇവരെ ഒരാളായി കാണും. സ്കൂൾ ഫീസ് ബാക്കിയും ട്രിപ്പ് ബാക്കിയും ഒരൊറ്റ സന്ദേശത്തിൽ വരും.
⛽ ചെലവുകൾ (ഡീസൽ, ശമ്പളം, റിപ്പയർ)
  1. Money ടാബ് → Expenses → +.
  2. ഇനം തിരഞ്ഞെടുക്കുക: ⛽ Diesel, 🔧 Maintenance, 👨‍✈️ Driver salary, 🛡️ Insurance & tax, 📦 Other.
  3. തുകയും തീയതിയും (കുറിപ്പ് ഓപ്ഷണൽ) കൊടുത്ത് Save.
ചെലവ് അന്നന്ന് ചേർത്താൽ Home-ലെ ലാഭം/നഷ്ടം ശരിയായി കിട്ടും. തിരുത്താനും ഒഴിവാക്കാനും ഓരോ എൻട്രിയുടെയും താഴെ Edit / Delete ഉണ്ട്.
📊 Home സ്ക്രീൻ വായിക്കാൻ

മുകളിൽ മാസം തിരഞ്ഞെടുക്കാം. അതനുസരിച്ച് കണക്ക് മാറും.

ഭാഗംഅർത്ഥം
Net profitആ മാസത്തെ വരവ് മൈനസ് ചെലവ്.
Fees receivedആ മാസം പണം കിട്ടിയ ഫീസ്. ഏത് മാസത്തെ ഫീസ് ആണെങ്കിലും (പഴയ ബാക്കി, ഈ മാസത്തേത്, മുൻകൂർ), കിട്ടിയ മാസത്തിലാണ് കൂട്ടുന്നത്.
Pending · all monthsഎല്ലാ മാസങ്ങളിലെയും ബാക്കി ആകെ, എത്ര കുട്ടികൾ ബാക്കി ഉണ്ട് എന്നും.
Expensesആ മാസത്തെ ചെലവ്.
Studentsകുട്ടികളുടെ എണ്ണം, എല്ലാം അടച്ചവർ എത്ര.
Income vs Expensesകഴിഞ്ഞ 6 മാസത്തെ വരവും ചെലവും ബാർ ചാർട്ടിൽ.
Where the money goesഡീസൽ, ശമ്പളം തുടങ്ങിയവയ്ക്ക് ചെലവിന്റെ എത്ര ശതമാനം.
ഇതിൽ വരവ് = ട്രിപ്പ് വരവ് (Paid) + കിട്ടിയ ഫീസ്.
🚐 ഒന്നിലധികം വണ്ടികൾ

ഒരു അക്കൗണ്ടിൽ എത്ര വണ്ടി വേണമെങ്കിലും ചേർക്കാം. ഓരോ വണ്ടിയുടെയും കുട്ടികൾ, ഫീസ്, ചെലവ്, ട്രിപ്പ് വരവ്, ലാഭം എല്ലാം പൂർണമായി വേറെ വേറെ ആയിരിക്കും.

  • പുതിയ വണ്ടി: ☰ → Vehicles → + Add vehicle.
  • വണ്ടി മാറാൻ: ഏത് സ്ക്രീനിലും മുകളിൽ കാണുന്ന 🚌 വണ്ടിയുടെ പേര് ▾ അമർത്തി തിരഞ്ഞെടുക്കുക.
  • ഓരോ വണ്ടിക്കും സ്വന്തം UPI ID, WhatsApp ഗ്രൂപ്പ് ലിങ്ക് കൊടുക്കാം (ഓപ്ഷണൽ).
ഒരു വണ്ടി ഡിലീറ്റ് ചെയ്താൽ അതിലെ എല്ലാ കുട്ടികളും പേയ്‌മെന്റുകളും ചെലവുകളും സ്ഥിരമായി പോകും. ഒന്ന് എപ്പോഴും വേണം.
💾 ബാക്കപ്പ് (നിർബന്ധമായും മറക്കരുത്)
ആപ്പ് തനിയെ ബാക്കപ്പ് എടുക്കില്ല. അബദ്ധത്തിൽ എന്തെങ്കിലും ഡിലീറ്റ് ആയാൽ തിരിച്ചെടുക്കാനുള്ള ഏക വഴി നിങ്ങളുടെ ബാക്കപ്പ് ഫയലാണ്. മാസാവസാനം ഒരിക്കൽ എടുക്കുക.

ബാക്കപ്പ് എടുക്കാൻ

  1. ☰ → Backup & Restore.
  2. Save to Drive / share അമർത്തി Google Drive, Gmail, അല്ലെങ്കിൽ WhatsApp (നിങ്ങളുടെ സ്വന്തം നമ്പറിലേക്ക്) തിരഞ്ഞെടുക്കുക. അല്ലെങ്കിൽ Download to phone.
  3. ഓപ്ഷൻ ഉണ്ടെങ്കിൽ Back up to Google Drive: ഡ്രൈവിൽ Pickora → ആ മാസത്തിന്റെ ഫോൾഡർ → ഫയൽ എന്ന ക്രമത്തിൽ സൂക്ഷിക്കും.

തിരിച്ചെടുക്കാൻ

  1. Choose backup file (അല്ലെങ്കിൽ Restore from Drive) → ഫയൽ തിരഞ്ഞെടുക്കുക.
  2. Yes, restore അമർത്തുക.
Restore ചെയ്താൽ ഇപ്പോഴുള്ള എല്ലാ ഡാറ്റയും ബാക്കപ്പിലുള്ളതുകൊണ്ട് മാറ്റപ്പെടും. സംശയമുണ്ടെങ്കിൽ ആദ്യം ഒരു പുതിയ ബാക്കപ്പ് എടുക്കുക.
📶 ഇന്റർനെറ്റ് ഇല്ലാത്തപ്പോൾ
  • ആപ്പ് തുറക്കും. കുട്ടികളെയും ബാക്കിയും കാണാം, പുതിയത് ചേർക്കാം, തിരുത്താം.
  • മുകളിൽ ഓറഞ്ച് അടയാളം: “Offline · 2 changes waiting to sync”.
  • നെറ്റ് വരുമ്പോൾ തനിയെ സെർവറിലേക്ക് പോകും. നീല “Syncing…” കണ്ട ശേഷം അടയാളം മായും. നിങ്ങൾ ഒന്നും ചെയ്യേണ്ട.
ആദ്യം ഇന്റർനെറ്റ് ഉള്ളപ്പോൾ ഒരിക്കൽ ലോഗിൻ ചെയ്ത് ആപ്പ് തുറന്നിരിക്കണം. ആ ഫോണിൽ അങ്ങനെ ചെയ്തിട്ടില്ലെങ്കിൽ ഓഫ്‌ലൈനിൽ തുറക്കില്ല.
ഒരേ അക്കൗണ്ട് രണ്ട് ഫോണിൽ ഒരേ സമയം ഓഫ്‌ലൈൻ ആയി ഉപയോഗിക്കരുത്. രണ്ടിലും മാറ്റിയാൽ അവസാനം സിങ്ക് ആകുന്നത് ജയിക്കും, ഒരു മാറ്റം നഷ്ടപ്പെടാം.

ഓഫ്‌ലൈനിൽ പറ്റാത്തവ: ലോഗിൻ, WhatsApp അയയ്ക്കൽ, Google Drive ബാക്കപ്പ്, പാസ്‌വേഡ് മാറ്റൽ. സിങ്ക് ആകാത്ത മാറ്റം ഉള്ളപ്പോൾ ലോഗൗട്ട് ചെയ്യാൻ പറ്റില്ല (ഡാറ്റ നഷ്ടപ്പെടാതിരിക്കാൻ).

⚠️ ശ്രദ്ധിക്കേണ്ട കാര്യങ്ങൾ

✅ ചെയ്യുക

  • ഫീസ് കിട്ടിയ ഉടനെ രേഖപ്പെടുത്തുക.
  • രക്ഷിതാവിന്റെ ഫോൺ 10 അക്കം ശരിയായി കൊടുക്കുക.
  • മാസത്തിൽ ഒരിക്കൽ ബാക്കപ്പ് എടുക്കുക.
  • UPI ID രണ്ടുതവണ പരിശോധിക്കുക.
  • ചെലവ് അന്നന്ന് ചേർക്കുക.
  • ആദ്യം ഒന്ന് രണ്ട് കുട്ടികളെ വച്ച് പരീക്ഷിച്ച് നോക്കുക.
  • ഫോണിന് ലോക്ക് വയ്ക്കുക.

❌ ചെയ്യരുത്

  • പാസ്‌വേഡ് ആരുമായും പങ്കിടരുത്.
  • Remove / Delete ചിന്തിക്കാതെ അമർത്തരുത് (തിരിച്ചെടുക്കാൻ ബാക്കപ്പ് മാത്രമേ വഴിയുള്ളൂ).
  • രണ്ട് ഫോണിൽ ഒരേ സമയം ഓഫ്‌ലൈൻ ജോലി ചെയ്യരുത്.
  • തെറ്റായ UPI ID കൊടുക്കരുത്.
  • കുട്ടിയുടെ ഫോൺ നമ്പർ ഇല്ലാതെ വിടരുത് (റിമൈൻഡർ അയയ്ക്കാൻ പറ്റില്ല).

മറ്റ് ചെറിയ കാര്യങ്ങൾ

  • തീയതികൾ ദിവസം-മാസം-വർഷം (09-11-2026) രീതിയിൽ ആണ് കാണിക്കുക.
  • ഫോണിന്റെ Back ബട്ടൺ ഓരോ സ്ക്രീനും പിന്നോട്ട് കൊണ്ടുപോകും. Home-ൽ എത്തിയാൽ “Exit Pickora?” എന്ന് ചോദിക്കും.
  • എന്തെങ്കിലും ഡിലീറ്റ് ചെയ്യുമ്പോൾ എപ്പോഴും ഉറപ്പ് ചോദിക്കും. വായിച്ച ശേഷം മാത്രം “Yes” അമർത്തുക.
  • ഫ്രീ ട്രയൽ/കാലാവധി തീയതി ☰ → Settings-ൽ കാണാം.
  • ഓരോ ഓപ്പറേറ്റർക്കും സ്വന്തം അക്കൗണ്ട്. നിങ്ങളുടെ കുട്ടികളുടെ വിവരങ്ങൾ മറ്റ് ഓപ്പറേറ്റർമാർക്ക് കാണാൻ പറ്റില്ല.
❓ സാധാരണ സംശയങ്ങൾ

ഫോൺ മാറ്റിയാൽ ഡാറ്റ പോകുമോ?

ഇല്ല. പുതിയ ഫോണിൽ ആപ്പ് തുറന്ന് അതേ ഇമെയിലും പാസ്‌വേഡും കൊണ്ട് ലോഗിൻ ചെയ്താൽ എല്ലാം കാണും.

ഒരു പേയ്‌മെന്റ് തെറ്റി ചേർത്തു, എന്ത് ചെയ്യും?

Fees → ആ കുട്ടി → View payment history → പേയ്‌മെന്റിന്റെ Edit (തുക/തീയതി മാറ്റാൻ) അല്ലെങ്കിൽ Delete.

Settings-ൽ UPI ID ചേർത്തിട്ടുണ്ടോ എന്ന് നോക്കുക, ഇന്റർനെറ്റ് ഉണ്ടോ എന്നും.

ഒരു കുട്ടി നിർത്തി, എന്ത് ചെയ്യും?

കുട്ടിയെ ടാപ്പ് ചെയ്ത് Remove. പഴയ പേയ്‌മെന്റ് രേഖകൾ കൂടി പോകുമെന്ന് ഓർക്കുക, വേണമെങ്കിൽ മുമ്പ് ബാക്കപ്പ് എടുക്കുക.

ആപ്പിൽ പുതിയ മാറ്റം കാണുന്നില്ല

ആപ്പ് പൂർണമായി അടച്ച് (recent apps-ൽ നിന്ന് നീക്കി) ഇന്റർനെറ്റ് ഓണാക്കി വീണ്ടും തുറക്കുക. ചിലപ്പോൾ രണ്ടുതവണ വേണ്ടി വരും.

ഇമെയിൽ വരുന്നില്ല (പാസ്‌വേഡ് മാറ്റാൻ)

Spam ഫോൾഡർ നോക്കുക. കുറച്ച് മിനിറ്റ് കാത്തിരിക്കുക. ഇല്ലെങ്കിൽ താഴെ കൊടുത്ത സഹായ നമ്പറിൽ ബന്ധപ്പെടുക.
